# 🌐 Mottanet 2026 - Template Institucional

![Preview do Projeto](https://raw.githubusercontent.com)

Projeto de modernização do portal institucional da **Mottanet**, focado em performance, experiência do usuário (UX) e apresentação dos novos planos de fibra óptica e serviços de streaming (MottaSim, MottaVision).

## 🚀 Tecnologias Utilizadas

Abaixo estão as principais tecnologias e ferramentas aplicadas neste template:

*   **HTML5** & **CSS3** (Custom Properties, Flexbox, Grid)
*   **JavaScript** (Manipulação de DOM e interatividade)
*   **Assets Otimizados:** Uso de formatos modernos como `.webp` e `.webm` para máxima velocidade.

## 🛠️ Funcionalidades

- [x] **Hero Section:** Banner de impacto com suporte a vídeo.
- [x] **Planos de Fibra:** Seção interativa com detalhes de pacotes e combos.
- [x] **Ecosistema Mottanet:** Integração visual de serviços adicionais (MottaSim, WatchBR).
- [x] **Páginas de Filiais:** Estrutura dinâmica para diferentes cidades.
- [x] **Design Responsivo:** Adaptado para dispositivos móveis e desktop.
